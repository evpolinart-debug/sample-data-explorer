# 🔍 Sample Data Explorer для Google Colab

Один файл с кодом, который превращает папку `/content/sample_data` в Google Colab в красивый интерактивный обзор данных: таблицы, графики, проверка качества, поиск и HTML-отчёт.

Код сам находит все файлы в папке и подстраивается под стандартные наборы данных Colab (California Housing, MNIST, квартет Энскомба, README), а также работает с любыми вашими CSV и JSON.

## 🚀 Как запустить

1. Откройте новый ноутбук в [Google Colab](https://colab.research.google.com/).
2. Скопируйте всё содержимое файла [`sample_data_explorer.py`](sample_data_explorer.py) в одну ячейку.
3. Нажмите **Shift + Enter**.

Устанавливать ничего не нужно: все библиотеки (pandas, numpy, matplotlib, seaborn, ipywidgets) в Colab уже есть.

Чтобы исследовать другую папку, поменяйте переменную `DATA_DIR` в начале кода.

## ✨ Возможности

| № | Раздел | Что делает |
|---|--------|------------|
| 1 | 📋 Инвентаризация | Таблица всех файлов: иконка типа, размер с цветной полоской, число строк и колонок, дата изменения |
| 2 | 🩺 Здоровье данных | Доля пропусков, дубликатов и выбросов (метод IQR) для каждой таблицы и итоговая оценка от 0 до 100 |
| 3 | 👀 Превью | Первые строки и описательная статистика таблиц, содержимое JSON и текстовых файлов |
| 4 | 🔥 Корреляции | Тепловая карта корреляций для каждой таблицы с числовыми колонками |
| 5 | 🗺 Карта Калифорнии | Точки районов на координатах: цвет — стоимость жилья, размер — население; плюс самый дорогой район |
| 6 | ✍️ MNIST | Галерея из 30 случайных рукописных цифр и «средний портрет» каждой цифры от 0 до 9 |
| 7 | 🎭 Квартет Энскомба | Четыре набора с почти одинаковой статистикой, но совершенно разными графиками и линиями регрессии |
| 8 | 🎲 Случайная запись | Случайная строка из любой таблицы |
| 9 | 🔎 Поиск | Поиск текста по всем файлам папки с подсветкой совпадений |
| 10 | 🎛 Интерактивный исследователь | Выбор файла, колонки и типа графика (гистограмма, boxplot, топ значений) с ползунком числа корзин |
| 11 | 📄 HTML-отчёт | Сохранение сводного отчёта в файл и автоматическое скачивание |

Разделы 5–7 появляются только тогда, когда в папке есть подходящие данные.

## 🧰 Команды после запуска

```python
search("ocean")                            # найти текст во всех файлах
make_report()                              # сохранить и скачать HTML-отчёт
DATA["california_housing_train.csv"]       # получить файл как pandas DataFrame
TABLES                                     # словарь всех загруженных таблиц
```

## 🧠 Как устроен код

- **Загрузка.** Функция `load_file` определяет формат по расширению: CSV читается в DataFrame (MNIST — без заголовка), JSON — в DataFrame или обычный объект, остальное — как текст. Все файлы складываются в словарь `DATA`, таблицы — в `TABLES`.
- **Распознавание наборов.** MNIST определяется по имени файла или по 785 колонкам (метка + 28×28 пикселей). Карта Калифорнии строится, если есть колонки `longitude`, `latitude`, `median_house_value`. Квартет Энскомба — если есть `Series`, `X`, `Y`.
- **Оформление.** Функция `banner` рисует цветные HTML-заголовки разделов, таблицы раскрашиваются через `pandas.Styler`.
- **Интерактив.** Виджеты `ipywidgets` связаны с функцией `draw` через `interactive_output`, поэтому график перерисовывается при любом изменении настроек.
- **Устойчивость.** Ошибки чтения файлов не останавливают работу, а показываются в превью; без `ipywidgets` код продолжает работать, а поиск доступен через `search()`.

## 📦 Требования

Python 3.9+, pandas, numpy, matplotlib, seaborn, ipywidgets (опционально). В Google Colab всё уже установлено.
